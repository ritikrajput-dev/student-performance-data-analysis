# student-performance-data-analysis

## Overview
This project performs Exploratory Data Analysis (EDA) on a student performance dataset using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- NumPy

## Analysis Performed
- Data Cleaning
- Average Score Calculation
- GroupBy Aggregation
- Data Visualization

## Objective
To analyze student performance patterns and generate meaningful insights using structured data analysis techniques.

## Files
- analysis.py — Python code for analysis
- data.csv — Dataset used for analysis
- README.md — Project documentation
